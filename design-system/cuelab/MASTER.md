# CueLab design system

UI/UX Pro Max's sports and entertainment research informed the red palette, condensed display typography, and single primary action. CueLab uses warm ivory and charcoal surfaces with cranberry accents drawn from its existing brand.

| Role | Light | Dark |
| --- | --- | --- |
| Page background | `#FBF7F3` | `#191418` |
| Form surface | `#FFFDFB` | `#271E24` |
| Primary text | `#211A1B` | `#FFF3EE` |
| Secondary text | `#645356` | `#D0B9BD` |
| Field border | `#9A8589` | `#8A7079` |
| Focus, links, and errors | `#A92032` | `#FF9DA6` |
| Primary action | `#A92032` | `#A92032` |
| Primary action hover | `#912031` | `#912031` |
| Primary action text | `#FFF8F5` | `#FFF8F5` |

Primary and secondary text measure 16.85:1 and 7.10:1 against the light surface, and 14.88:1 and 8.75:1 against the dark surface. Primary action text measures 6.80:1 against the default fill. Field borders measure 3.23:1 and 4.05:1 against their light and dark field backgrounds.

Use Barlow Condensed at weight 600 for display headings and Geist for interface text. Keep field text at 16 px and use the existing CueLab wordmark and Heroicons. Use 8 px control radii, 16 px panel radii, and spacing in multiples of 8 px.

Give each page one primary action. Keep visible field labels and pair error color with error text. Provide a 2 px focus outline and respect reduced motion.
